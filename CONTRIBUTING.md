## Contributing to Chromaticc

Thank you for wanting to help! Here's how to get started:

### Reporting Bugs
- Search existing issues to avoid duplicates.
- Use the Bug Report template (if available) or describe the bug clearly: what you did, what you expected, what actually happened.
- Include screenshots or error messages.

### Suggesting Features
- Use the Suggestion template or describe your idea and why it would be useful.
- Attach mockups or examples if you have them.

### Pull Requests
1. Fork the repository.
2. Create a branch for your change (`git checkout -b feature/my-widget`).
3. Make your changes, test them locally (or on Vercel Preview).
4. Commit with clear messages.
5. Open a Pull Request and describe what you've done.

### Code Style
- Use the same style as the existing code.
- Keep widgets self‑contained.
- All icons should be inline SVGs.
