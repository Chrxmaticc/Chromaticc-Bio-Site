## What is Chromaticc?

Chromaticc is a **free, open‑source profile builder** that lets you create fully customisable bio pages. Think of it as a more powerful, more flexible alternative to existing bio tools — but with **complete control**. Move, resize, rotate every element, add widgets like music players, Discord status, tech stacks, and even inject your own HTML/CSS/JS.

It looks goofy on the outside, but under the hood it’s a serious platform. Built for developers, gamers, artists, and anyone who wants a profile that actually represents them.

---

## Features (all free, forever)

### Customisation
- Full drag‑and‑drop widget builder
- Live edit preview (see changes in real time)
- 8+ background designs (gradient, image, video, animated)
- Glassmorphism, neon text, gradient text, custom cursors, overlay effects
- Custom fonts (Inter, Orbitron, Roboto Mono, plus TTF upload)
- Black/white/silver theme with glass morphism everywhere

### Music & Audio
- Glass Music Player (Apple‑style frosted glass)
- Regular audio widget with volume control
- Click‑to‑Enter audio (plays when visitor clicks)
- Lyric sync embed (auto‑match lyrics to uploaded audio)
- Audio visualiser (real‑time bars reacting to your track)

### Widgets (40+ and growing)
- Text (plain, gradient, neon)
- Profile circle, image, video
- Audio, glass music player, audio visualiser
- Section divider, shape, divider, badges
- YouTube, Discord, Spotify, GitHub, Twitter, Instagram, Twitch, Reddit, TikTok, SoundCloud embeds
- Clock, weather badge, countdown, days counter
- Tech stack, GitHub stats, game library
- Quote ticker, click counter, mini poll, guestbook
- Discord status (via Lanyard), visitor counter
- Code widget (inject your own HTML/CSS/JS)
- Custom cursor, font selector, TTF upload, page indicator

### Performance & Privacy
- 100% uptime (Vercel + PostgreSQL)
- Zero trackers, zero ads
- Instant CDN file uploads (Vercel Blob)
- Custom subdomains supported

### Community
- User accounts with personal URLs (`/username`)
- Simplified mode for quick setup
- Public profiles with live previews
- Discord community (146+ members)

## How to create your bio

1. Visit **[chromaticc.creepers.lol](https://chromaticc.creepers.lol)**
2. Sign up (just a username and password, no email required)
3. Open the **Dashboard** → **Edit Mode**
4. Drag widgets from the sidebar, upload your images/audio, and customise everything
5. Save and share your link: `https://chromaticc.creepers.lol/yourusername`

## Tech Stack

| Layer          | Technology                           |
|----------------|--------------------------------------|
| Frontend       | HTML, CSS, JavaScript (vanilla)      |
| Backend        | Node.js, Vercel Serverless Functions |
| Database       | PostgreSQL                           |
| File Storage   | Vercel Blob (CDN)                    |
| Auth           | JWT + bcryptjs                       |
| Drag & Drop    | interact.js                          |
| Discord Status | Lanyard API                          |
| Weather        | wttr.in                              |
| Icons          | Inline SVGs                          |
